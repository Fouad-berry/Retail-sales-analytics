# 📊 Retail Sales Analytics

Interactive Business Intelligence dashboard developed with **Microsoft Power BI** to analyze retail sales, advertising performance and commercial KPIs.

The objective of this project is to transform raw sales data into actionable insights through interactive visualizations and dynamic KPIs.

---

## 🎯 Project Objectives

This project aims to answer key business questions:

- What are the main sales markets?
- Which brands generate the highest revenue?
- Which products perform best?
- How does revenue evolve over time?
- How efficient are advertising investments?
- Which countries and brands have the best ROAS?
- How does performance change depending on the selected period, country or brand?

---

## 📈 Dashboard

The dashboard provides an interactive overview of commercial and advertising performance.

### Key Performance Indicators

- 💰 **Total Revenue**
- 📢 **Advertising Spend**
- 📦 **Units Sold**
- 📊 **Global ROAS**
- 💎 **Estimated Margin**

### Main Analyses

- Revenue by country
- ROAS by brand
- Revenue evolution over time
- Top 10 products by revenue
- Revenue and ROAS by brand
- ROAS by country
- Dynamic business insights

### Interactive Filters

Users can filter the dashboard by:

- **Brand**
- **Country**
- **Analysis Period**

All KPIs and visualizations dynamically update according to the selected filters.

---

## 🧠 Dynamic Insights

The dashboard includes dynamic insights built with **DAX measures**.

These insights automatically identify:

- The country with the highest revenue
- The brand with the highest ROAS
- The product with the highest revenue
